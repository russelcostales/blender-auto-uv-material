# Blender Auto UV Material

A lightweight Blender add-on that automatically assigns and fixes UV grid materials for selected objects.

## Features

- Assigns a unique material matching each object's name.
- Automatically creates and configures UV grid textures.
- Repairs incorrect material setups.
- Removes unnecessary material slots and discarded unused materials.
- Preserves unselected objects.
- Reports changes after execution.

## Installation

1. Download `auto-uv-material.py`.
2. Navigate to Edit > Preferences > Add-ons.
3. Select Install from Disk and choose the downloaded file.
4. Enable Auto UV Material.

## Usage

1. Select your mesh objects in Object Mode.
2. Press `N` to open the viewport sidebar.
3. Navigate to the Auto UV Material tab.
4. Click **Assign UV Materials**.

Existing custom materials on selected objects may be replaced.

## Compatibility

Blender 4.2+
